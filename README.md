# Mera Word Search Journey (Ink & Starlight)

> Words become paths. Paths become adventures.

A hybrid **Word Search + Light RPG** mobile game built entirely in **C#**, targeting Android (Google Play Store).

## 🎮 About the Game

Mera Word Search Journey blends classic word search puzzles with light RPG progression. Players explore 6 handcrafted worlds, solve word puzzles, defeat bosses, collect pets, and build their base — all across 2000 levels.

## ✨ Features

- 🔤 **2000 Levels** across 6 unique worlds
- 🎭 **Light RPG Systems** — pets, base building, progression
- 👹 **Boss Battles** at world milestones
- 🧠 **Adaptive Difficulty** — puzzles adjust to player skill
- ☁️ **Cloud Save & Sync**
- 📱 **Mobile-first** — built for Android (Google Play Store)

## 🛠️ Tech Stack

- **Language:** C# (.NET)
- **Engine:** Unity
- **Target Platform:** Android (Google Play Store)
- **Backend:** TBD (cloud save)
