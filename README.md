# Mera Word Search Journey (Ink & Starlight)

**Words become paths. Paths become adventures.**

A rich Word Search + Light RPG hybrid game featuring 2000 levels across 6 beautiful worlds, bosses, pets, base building, skills, daily challenges, adaptive difficulty, and much more.

## Features
- 2000 Levels across 6 Journey Worlds
- 30+ Game Modes
- RPG Systems: Pets, Skill Tree, Base Crafting
- Multi-language support
- Accessibility options

## Tech Stack
- Frontend: React 19 + TypeScript + Vite 8
- Routing: TanStack Router + Start
- State: Zustand
- Styling: Tailwind CSS v4 + Radix UI

## Getting Started
Prerequisites: Node.js 22+ and npm

Commands:
npm install
npm run dev
npm run build
