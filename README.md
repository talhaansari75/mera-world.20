# Mera Word Search Journey (Ink & Starlight)

> Words become paths. Paths become adventures.

A hybrid **Word Search + Light RPG** mobile game built entirely in **C#**, targeting Android (Google Play Store).

## 🎮 About

Blends classic word search puzzles with light RPG progression. Explore 6 worlds, solve puzzles, defeat bosses, collect pets, and build your base across 2000 levels.

## ✨ Features

- 🔤 **2000 Levels** across 6 unique worlds
- 🎭 **Light RPG Systems** — pets, base building, progression
- 👹 **Boss Battles** at world milestones
- 🧠 **Adaptive Difficulty**
- ☁️ **Cloud Save & Sync**
- 📱 **Android first** (Google Play Store target)

## 🛠️ Tech Stack

- **Language:** C# (.NET)
- **Engine:** Unity
- **Platform:** Android (Google Play Store)
