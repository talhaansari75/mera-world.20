# Mera Word Search Journey — Game Design Document

## Elevator Pitch

A relaxing word search puzzle game with a light RPG twist. 
Players travel through 6 handcrafted worlds, solve word puzzles, 
collect pets, and build their base.

## Core Loop

1. Player opens app → Home screen
2. Selects level → Sees 8x8 (or bigger) letter grid + word list
3. Drags finger to select letters
4. Valid word found → animation + reward
5. All words found → Level complete → stars + coins
6. Back to home → unlock next level

## Target Audience

- Age 25-60 (casual puzzle players)
- Short sessions (2-5 min)
- Enjoy Words of Wonders, Wordscapes, Wordle
- Like progression and light collection

## Monetization (planned)

- Rewarded ads for hints
- Banner ads on menus (not during play)
- IAP: coin packs, no-ads, pet bundles
- Daily rewards

## Worlds (planned)

1. **Green Meadows** — easy words, tutorial
2. **Sunny Beach** — nature words
3. **Mystic Forest** — fantasy creatures
4. **Crystal Mountains** — gem/metal words
5. **Ancient Desert** — history words
6. **Starlight Sky** — cosmic words

Each world: 30-40 levels, unique background, unique pet.

## Difficulty Progression

- Levels 1-30: 3-4 letter words, 6x6 grid, 4-5 words
- Levels 31-60: 4-5 letter words, 8x8 grid, 5-6 words
- Levels 61-100: mixed, 9x9 grid, 6-8 words
- Levels 100+: diagonal only, 10x10 grid, 8+ words

## Progression Systems

- **Stars**: 3 per level (based on time + hints used)
- **Coins**: earned per level, spent on hints
- **Pets**: unlock via milestones, give passive bonuses
- **Base**: visual progression, no gameplay impact

## Session Length

Target: 2-5 minutes per level.
- Fast levels: 60-90 seconds
- Medium: 2-3 min
- Hard: 4-5 min

## Art Style

- 2D cartoon, glossy
- Royal blue + gold palette
- Friendly, warm, inviting
- Mobile portrait orientation

## Audio (planned)

- Soft background music per world
- Satisfying "clink" when letter selected
- "Ding" when word found
- Celebration jingle on level complete
- UI click sounds

## Non-Goals

- No real-time multiplayer (v1)
- No iOS (v1)
- No complex RPG combat
- No social features (v1)

## Success Metrics

- Day 1 retention: >40%
- Day 7 retention: >15%
- Average session: 8-15 min
- Level completion rate: >70%
